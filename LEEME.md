# Paquete de prompts: MAX Sport Manager

Incluye:

- `01_PROMPT_MAESTRO.md`: contrato funcional y técnico completo para Codex.
- `02_PROMPTS_POR_FASES.md`: 8 fases (0-7) listas para copiar, más prompt de seguimiento.

## Uso rápido

1. Crear un repositorio vacío `max-sport-manager`.
2. Copiar estos dos archivos dentro de una carpeta `docs/` del repositorio.
3. El archivo `MASTER_PROMPT.md` ya está listo para copiar directamente a `docs/MASTER_PROMPT.md`.
4. Abrir Codex desde la terminal en la raíz del proyecto.
5. Pegar el prompt maestro y luego la Fase 0. Seguir fase por fase, comprobando tests.

**Nota:** tasa histórica COP, VES y USDT: no se consultan automáticamente ni se adivinan; el usuario las confirma. En este paquete el ejemplo de compra 3×80.000 + 5×80.000 + 7×84.000 COP suma **1.228.000 COP**, equivalente a **USD 307** a 4.000 COP/USD.
